# 헬퍼탐(미니)

대학생의 **산업 탐색 · 직무 탐색 · 준비계획** 3개 기능만 담은 헬퍼탐(헬퍼손 산업직무 탐색기)의 경량 버전입니다.

- 회원가입 없이 브라우저에서 바로 사용 (데이터는 이 기기 브라우저에만 저장)
- 50개 산업 × 95개 직무, 511개 대표기업 데이터 내장
- 단일 HTML 파일로 동작하는 정적 웹앱 — 별도 서버·빌드 과정 불필요

## 온라인으로 열기

GitHub Pages가 활성화되면 아래 주소에서 바로 이용할 수 있습니다.

```
https://helper83.github.io/helpertom-mini/
```

(저장소 Settings → Pages 에서 Source를 `Deploy from a branch` / `main` / `/(root)` 로 설정하면 위 주소가 활성화됩니다.)

## 로컬에서 열기

`index.html` 파일을 내려받아 더블클릭하거나 브라우저로 열면 바로 실행됩니다.
