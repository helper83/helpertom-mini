# 산업×직무 연결 보강 근거 (v1.5 · 2026-10-14)

대상: 기존에 "직접 연결(2점) 이상 산업이 하나도 없던" 직무 8개. 상향 58건(하향 없음).
점수 기준: 3=핵심 연결, 2=직접 연결, 1=일부 연결(추정·공고 확인 필요).
판정 원칙: (a) 앱 내 확인기업(공식 채용 URL로 검증된 기업 데이터)에서 해당 직무 채용이 확인되면 2, 같은 산업 확인기업 5곳 이상이면 3
(b) 웹 출처 2건 이상이 같은 연결을 뒷받침하면 2~3 (c) 출처 1건·간접 근거는 1로 표시하고 "추정" 처리.
확인하지 못한 연결은 넣지 않았습니다.
